# Один граф, три алгоритма

Интерактивный тренажёр на русском языке для обхода в ширину (BFS), обхода в глубину (DFS) и алгоритма Краскала.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сборка для запуска не требуются. Стили, код и данные графа встроены в страницу.

Для запуска через локальный сервер из каталога проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Использование

- Выберите алгоритм в списке.
- Переключайте шаги кнопками «Назад» и «Шаг вперёд».
- Следите за очередью BFS, цепочкой возврата DFS или рёбрами остова Краскала.
- Последний просмотренный шаг сохраняется в браузере, если локальное хранилище доступно.

Обходы начинаются из вершины 1. Соседи рассматриваются по возрастанию номера. В графе 7 вершин и 8 рёбер. Толстые линии обозначают выбранные рёбра дерева, пунктир показывает ребро, пропущенное Краскалом из-за цикла.

## Результаты для проверки

- BFS — `1, 2, 3, 4, 7, 5, 6`.
- DFS — `1, 2, 4, 7, 3, 5, 6`.
- Краскал — рёбра `2–4, 3–5, 5–6, 6–7, 1–3, 1–2`, суммарный вес 23.

## Файлы

- `index.html` — готовый автономный сайт, включая стили и среду выполнения визуализации.
- `visualization.html` — исходный HTML-фрагмент с логикой алгоритмов, графикой и элементами управления. Это исходник для редактирования и повторного экспорта через навык visualize в Codex.

Для размещения сайта откройте Settings → Pages в репозитории. Выберите Deploy from a branch, ветку `main` и каталог `/ (root)`, затем сохраните настройки.
